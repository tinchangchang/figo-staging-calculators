# FIGO Staging Calculators v1.4.0

Released 26 September 2026.

## Changes

- Removed the word "provisional" from calculator results and copied summaries.
- Unanswered fields use the first clinical option as the negative or baseline calculation default while the visible control remains unselected.
- Stage text begins in a light burgundy and becomes progressively more saturated as required fields are explicitly confirmed.
- Full FIGO burgundy indicates that all required fields for the displayed workflow have been answered.
- Reordered the seven calculators alphabetically on the main menu.
- Enlarged the "Calculator menu" return link in every calculator.

## Safety note

Color indicates input completeness, not diagnostic certainty. Every result remains a staging aid and requires confirmation against complete clinical, imaging, operative, pathological, molecular, and multidisciplinary information as applicable.
